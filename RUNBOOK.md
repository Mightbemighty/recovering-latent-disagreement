# Runbook for an isolated local copy

## Safety rules

- Do not bulk-import the scripts. Many have no main guard and load data or write outputs on import.
- Work in a disposable copy. Several programs overwrite fixed output names.
- Supply inputs according to `DATA.md`; no input data are included.
- Do not run downloads, full placebo/bootstrap batches, or CRSP processing unintentionally.
- No command below was executed for this source release.

Install package names from `requirements.txt`, then explicitly record actual versions.

## Main construction and evidence

Run from `3-代码文件/3-latent-disagreement/` after placing inputs:

```bash
python make_panel9.py
```

Check script-specific arguments before execution; some modules force `sys.argv` for their fixed specifications.

## Output and figure handling

Outputs go to `results/`, `figures/`, the utility output directory, or documented local intermediate paths. They are excluded from the release. No generated table or figure in this release is marked reproduced.

After `run_utility_repair_p9.py`, install the three manuscript figures with these exact filename mappings:

- `cer_path.pdf` → `fig_dcer_path_p9.pdf` (Figure 7)
- `sr_path.pdf` → `fig_dsr_path_p9.pdf` (Figure 8)
- `rolling60_cer_difference.pdf` → `fig_dcer_diff_rolling60_p9.pdf` (Figure 9)

The Spearman statement following Table 4 is generated by `run_evidence.py --panel9 --starts 2001 1991`: for the 2001 arm only, it joins the nine raw-unit absolute level–disagreement correlations from `panel9_qe_raw.csv` to the corresponding `gain` values and writes `h1_spearman_inputs_2001_p9.csv` and `h1_spearman_2001_p9.csv`. The printed standardized-panel Pearson statistic is a different diagnostic and is not the source of the manuscript's Spearman coefficient.
